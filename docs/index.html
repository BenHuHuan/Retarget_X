4-Stage Kinodynamic Architecture

Stage 1 · Kinematic IK

Enhanced hhtools

采用精确 SDK 脚底站立高度比 (1.2586) 彻底消除 1.3m 身高回退穿地 Bug，支持单/多姿态 (T90/T60/T90_elbow45) 整段择优。

Stage 2 · Core Bridge

Kinodynamic Conditioning

零相位 Savitzky-Golay 平滑（加速度毛刺降 12%–37%）+ 精确脚底胶囊体接触投影（穿地归零 0.00 mm 且保留腾空）+ 动力学难度画像。

Stage 3 · Physics MPC

Difficulty-Adaptive DTMR

按 low / medium / high 难度自动分配 MuJoCo Warp 采样预算、前瞻时域与时间相位弹性，并基于消融结论关闭 w_foot_slip。

Stage 4 · Audit & Export

Unified RL / Sim Delivery

输出运动学+动力学双维度质检报告，并导出标准 50 Hz .npz，可直接接入 xMimic / StableMimic / IsaacLab 训练。
